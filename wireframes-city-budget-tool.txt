========================================================================
03) EXPORT / IMPORT / RESET (LOCAL-ONLY)
========================================================================

Export
------
Click [Export JSON] to download JSON of the one current comparison:
- Selected cities + place_id metadata
- Per-city income inputs
- Per-city housing inputs
- Global pre-tax contributions + filing status
- Line-item monthly expenses
- Optional: last computed results snapshot + timestamps

Click [Export CSV] to download a flat file for Sheets/Excel:
- One row per city
- Includes: city name, baseline flag, income fields, housing fields, pre-tax settings, total monthly expenses,
  and outputs (take-home/mo, expenses/mo, leftover/mo, annual savings, deltas vs baseline)

Import
------
Click [Import] to load JSON and replace the current comparison.
On success: show banner “Comparison imported. Recalculate to refresh taxes/insights.”

Reset
-----
Click [Reset] → confirmation modal:
Title: Reset comparison?
Body: This clears the locally saved comparison on this device.
Buttons: [Cancel] [Reset]
